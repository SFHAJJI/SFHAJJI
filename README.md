# Soufien Hajji — AI & Data Architecture

I build production systems where AI, data engineering, cloud architecture, and verifiable evidence meet. Based in Luxembourg; working in English and French.

I am open to **AI/Data Solution Architect** and **AI Engineer** roles.

## Flagship work

| Project | Problem solved | Engineering evidence |
| --- | --- | --- |
| [Lex](https://law.soufien.lu) · [source](https://github.com/SFHAJJI/lex) | Find and compare what Luxembourg and reviewed EU law said at a chosen date. | Temporal ingestion, exact text and provenance, deterministic retrieval, gated local hybrid search, signed artifacts, MCP, Azure deployment, published architecture decisions and benchmarks. |
| [Energy Copilot](https://energy.soufien.lu) · [architecture](https://energy.soufien.lu/architecture.html) | Turn public geospatial, tender, tariff, and legal data into traceable solar-prospecting decisions. | Azure agentic RAG, deterministic tools, PostGIS, source citations, security controls, observability, cost controls, and explicit production gaps. |

The emphasis in both systems is not a chatbot demo. It is the less glamorous work that makes an AI product defensible: temporal data models, retrieval quality, provenance, failure modes, deployment safety, operational cost, and honest limitations.
